# 11. Chạy trong CI

## Lịch chạy đề xuất

| Khi nào | Lệnh | Mục đích |
| --- | --- | --- |
| Mỗi pull request | `check --mode replay --affected origin/<base>` | Nhanh, chặn merge khi có lỗi |
| Merge vào main | `check --mode replay` (toàn bộ) | Giữ baseline đầy đủ |
| Hằng đêm | `check --mode live`, `fuzz`, `adapters` | Bắt lỗi backend thật, chuỗi thao tác hiếm, widget |
| Khi API đổi | `check --mode record --update` (chạy tay) | Làm mới bản ghi |

## Workflow GitHub Actions

Bản đầy đủ: [`examples/github-workflow.yml`](../../examples/github-workflow.yml). Phần chính:

```yaml
name: flowcheck
on: pull_request
permissions: { contents: read, pull-requests: write }

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }                 # cần lịch sử cho --affected
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm build --mode test               # có plugin flowcheck nếu dùng --affected

      - name: Serve the build
        run: |
          pnpm preview --port 4173 --strictPort &
          for i in $(seq 1 30); do curl -sf http://localhost:4173/ >/dev/null && break; sleep 1; done

      - name: flowcheck
        run: pnpm exec flowcheck check --url http://localhost:4173/ --mode replay --affected origin/${{ github.base_ref }}

      - name: Comment on the pull request
        if: always() && hashFiles('.flowcheck/report.md') != ''
        env: { GH_TOKEN: ${{ github.token }} }
        run: gh pr comment ${{ github.event.pull_request.number }} --edit-last --create-if-none --body-file .flowcheck/report.md

      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: flowcheck
          path: |
            .flowcheck/
            !.flowcheck/screens/
```

## Kết quả trên PR

- **Comment trên PR** (lấy từ `.flowcheck/report.md`), được cập nhật tại chỗ mỗi lần push:
  - kết luận (`✅ no errors` hoặc `❌ N errors`);
  - graph thay đổi dạng diff;
  - danh sách lỗi;
  - độ phủ intent;
  - báo cáo đầy đủ gập bên dưới.
- **Job summary:** cùng nội dung, không cần token.
- **Artifact:** cả thư mục `.flowcheck/`, gồm `graph.html` để tải về xem (không có ảnh chụp).

## Khi PR thay đổi màn có chủ đích

Job fail với lỗi `app.graph.json is out of date` hoặc `button "X" is gone`. Trên máy dev:

```sh
flowcheck check --mode replay --update
git diff flowcheck/            # review thay đổi
git add flowcheck/ && git commit -m "Update flowcheck baseline"
```

## Lưu ý trong CI

- **Ảnh chụp tắt mặc định** khi có biến `CI`. Bật bằng `--screenshots` chỉ khi chắc chắn app không hiện dữ liệu cá nhân.
- Chạy trên **bản build** (`vite preview`) nhanh và giống production hơn dev server.
- Dùng **replay** để không cần backend trong CI.
- Chặn mọi dịch vụ ngoài (`block`).
